Run open-weight models on hardware you own.

Privacy, offline operation and a near-zero marginal cost per token stop being arguments you have to make once the model runs on a machine under your desk. This book covers the whole path: picking a model, running it well, fine-tuning it on your own documents, building agents and RAG on top, serving a team, and keeping the result defensible under the GDPR. 

curl -fsSL https://ollama.com/install.sh | sh    # runtime + model registry
ollama run <model>                               # chat in the terminal

Written for engineers and researchers. No cloud account required.
