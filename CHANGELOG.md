# Changelog

All notable changes to *The Local AI Field Guide* are documented here.
The book itself carries the version from `CITATION.cff`; tagged versions
(`v*`) trigger the release workflow in `.github/workflows/book.yml`,
which publishes PDF/EPUB/DOCX archives and auto-generated notes.

## [2.0.0] — 2026-10-18

First tagged release since the 1.0.0 snapshot. In between, the book moved
to a per-chapter build, gained a finished French edition, and absorbed the
material of Hugging Face's *Local AI Ecosystem with llama.cpp* talk deck.

### Added
- French edition: every chapter translated, French UI strings, per-language home page.
- Speculative decoding: the draft-and-verify loop, acceptance-decay arithmetic, and the three llama.cpp techniques (MTP, DFlash, EAGLE3) with working `llama serve` flags (Ch. 5).
- `llama bench` as the way to measure your own machine instead of trusting tables (Ch. 5).
- Quant-name anatomy: legacy `Q4_0`/`Q8_0` vs k-quants vs i-quants, Unsloth `UD-*` dynamic quants, Blackwell-only `MXFP4`/`NVFP4`, plus the `llama-imatrix` + `llama quantize` workflow for your own fine-tunes (Ch. 16).
- The four latency numbers users feel: TTFT, time per output token, throughput, end-to-end (Ch. 15).
- llama.cpp single-model multimodal CLI: `--image`, `/image`, `/audio` in one model (Ch. 14).
- Dense-vs-MoE memory placement (VRAM for dense, large unified memory for big MoEs) in Annex D; LFM2.5 230M in the edge tier (Ch. 2).
- "Our take" opinion blocks throughout; data figures for throughput and hardware tiers.
- Source annex: *Inference Engineering* (Philip Kiely & Baseten) and the Hugging Face deck cited as the source digested into Chapters 3, 5, 14–16 and Annex D.

### Changed
- One chapter per page on a native Quarto book project: collapsible sidebar, per-chapter PDF/EPUB/DOCX downloads and slide decks.
- Landing page with download cards, license footer, and a citable book (`CITATION.cff`, CC-BY-4.0).

### Infrastructure (contributors)
- Single-source bilingual pipeline: `chapters/_src/*.qmd` carry both languages; the `_quarto*.yml` configs are generated by `tools/build_book.py` and no longer tracked.
- One render path (`tools/render.sh`) shared by CI and local runs; CI renders EN on PRs, EN+FR on main and tags.
